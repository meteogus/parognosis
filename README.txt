PAROGNOSIS - FOLDER STRUCTURE

Folders:
- all folders: category folders and their source files to copy into html.
- html: final website files for manual WinSCP upload to grhost and updating the GitHub repository via GitHub Desktop.
- grhost: local notes/tools related to manual WinSCP uploads.
- github: local helper scripts.
- highslide: Highslide library files.
- Javascripts: JavaScript files used by the site.

BAT:
Run github\copy_all_folders_to_html.bat to copy files and subfolders from "all folders" into "html".
It does not delete files from html and does not convert PHP to HTML.

IMPORTANT:
This ZIP contains the folder structure and the copy BAT only. It does not contain your actual website files, Highslide/JavaScript library files, PHP-to-HTML converter, or Git repository. Add your real files to the corresponding folders before using it.
